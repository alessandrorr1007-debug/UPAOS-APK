# Informe de capturas de UPAO S

- Dispositivo físico modelo **2412DPC0AG**, Android **16**, API **36**.
- PNG de pantalla completa a **1220 × 2712 px**.
- Base Git inspeccionada **b5630f1**, con cambios locales de las fases anteriores, incluido el rediseño de Pagos. Se usó el APK debug ya instalado y se navegó con ADB y UI Automator.
- **65 pantallas y estados inventariados**. **40** tienen imágenes en ambos temas.
- **50** PNG en modo claro y **49** en modo oscuro. Total **99**.

## Privacidad

Se utilizó la sesión que ya estaba activa. Se cubrieron valores dinámicos y contenido personal con bloques opacos en copias locales, y se reforzó la cobertura en ventanas flotantes. Algunos textos funcionales dinámicos también quedaron cubiertos. El tamaño y la composición de las capturas se conservaron. El ZIP contiene únicamente las imágenes tratadas y los informes.

## Navegación y alcance

La navegación se realizó con los controles disponibles en el teléfono y el selector de tema de UPAO S. Los recorridos que dependen de recursos particulares de Canvas, avisos transitorios o configuraciones sensibles quedaron pendientes cuando no se alcanzó un estado verificable. En horarios la vista inicial corresponde al día mostrado por la app. Se evitó guardar credenciales, eliminar cuentas o datos, enviar mensajes y realizar operaciones financieras. El acceso a estados protegidos o a una nueva sesión requiere al propietario.
